Tools in this development release

One useful tool at a time. No accounts required for the QR generator.

QR
DEVELOPMENT PILOT

QR code generator

Create a downloadable QR code. Optional first-party click counts use a short redirect link; we store the destination, a label, total clicks, and the last-click time—not visitor identity, IP addresses, or device fingerprints.

PDF
LIVENew Tool

PDF tools

Private, browser-first basics: merge, split, rotate, compress, and convert. No upload-based processing until the privacy model is reviewed.
